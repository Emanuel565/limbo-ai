2. Finalidade e Descrição do Serviço

O Limbo AI Studio é uma ferramenta de produtividade para criadores de conteúdo que fornece:

  • Reenquadramento de vídeos para o formato vertical 9:16 (1080x1920);
  • Geração e queima de legendas com destaque de palavras-chave;
  • Análise preditiva de engajamento e métricas de retenção para criadores;
  • Publicação automatizada de vídeos através da TikTok Content Posting API oficial e da Meta Graph API.

3. Responsabilidade do Usuário

O usuário é o único responsável pelo conteúdo de áudio e vídeo submetido e publicado. É estritamente proibido utilizar a ferramenta para carregar conteúdos que violem direitos autorais ou que infrinjam as Diretrizes da Comunidade do TikTok.
